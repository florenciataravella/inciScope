InciScope is a web application designed to help users explore and understand chemical compounds commonly used in science, cosmetics, pharmaceuticals, and everyday products. By entering the name of a compound, users can instantly access key chemical properties, molecular information, structural images, and a concise description of the substance. The application integrates data from two trusted scientific resources: PubChem and Wikipedia. PubChem provides detailed chemical information such as molecular weight, molecular formula, hydrogen bond donor and acceptor counts, and IUPAC nomenclature. Wikipedia complements this information with accessible descriptions and background context, making scientific data easier to understand. The goal of InciScope is to bridge the gap between complex chemical databases and everyday users by presenting reliable information through a simple, intuitive, and responsive interface. Whether you are a student, researcher, cosmetic formulator, or simply curious about the ingredients found in products, InciScope offers a convenient way to learn more about chemical compounds. This project was developed as part of the WDD 330 Web Frontend Development course and demonstrates the use of modern JavaScript, asynchronous programming, API integration, responsive web design, and dynamic content rendering.

Technologies Used

  • JavaScript (ES6 Modules)
